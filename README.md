# vt-faculty-directory-scraper
Python web scraper that extracts and structures faculty data from Virginia Tech department directories using BeautifulSoup and regex.

This project scrapes faculty directory pages across three Virginia Tech departments (Computer Science, Business Information Technology, and Statistics), validates that each source URL is live, and parses instructor details — name, title, department, office, email, and phone — into a clean, deduplicated CSV dataset with unique record IDs
